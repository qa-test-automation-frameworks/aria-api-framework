# Code of Conduct

This project uses a simple professional conduct standard:

- Be respectful and specific in technical discussion.
- Critique code, tests, documentation, and design decisions without personal attacks.
- Do not share private credentials, private vulnerability details, or personal data in public issues or pull requests.
- Keep disagreements evidence-based and actionable.

Maintainers may edit, hide, or remove comments and contributions that violate these expectations.
